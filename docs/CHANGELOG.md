# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.5.0] - 2025-07-13
### Added
- Web application for displaying parsed document data
- Improved Telegram bot response messages with more user-friendly text

### Changed
- Replaced two database tables with a single unified table

## [2.0.0] - 2025-07-06
### Added
- Database for storing parsed document data
- English language support in the Telegram bot

### Changed
- Connected the Telegram bot, N8N agent, and database into an integrated system

## [1.0.0] - 2025-06-22
### Added
- Telegram bot for receiving documents
- N8N agent for processing and extracting data from documents
